# GazeCursor

Webcam-only gaze-controlled mouse with blink clicking, built with OpenCV and MediaPipe.

> **Status:** Phase 0 — project skeleton and webcam check.

## Quick Start

```bash
# Create and activate a virtual environment
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the webcam check
python main.py
```
